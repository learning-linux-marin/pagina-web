Project · Light follower

Light Seeker

A little robot head with two light-sensing “eyes” that turns on its servo “neck” to face the brightest light in the room. Point a phone flashlight at it and watch it follow you.

Time 1–2 h Level first project Soldering none Parts all in the kit

Try it first → drag the flashlight in the simulator. The bars are what the Arduino “sees”, and the orange chip shows which part of the code is running.

01 · The idea

How it works: eyes, brain, neck

The whole project is one loop that repeats about 60 times a second: read both eyes, compare them, nudge the neck toward the brighter side.

Eyes · photoresistors

A photoresistor (LDR) changes its resistance with light: bright light → low resistance, darkness → high resistance. We use two, one pointing a bit left and one a bit right.

Brain · Arduino UNO

analogRead() turns each eye’s voltage into a number from 0 (dark) to 1023 (bright). The code subtracts left − right to decide which way to turn.

Neck · servo motor

A hobby servo turns to an exact angle from 0° to 180° when you call servo.write(angle). The two eyes sit on top of it, so they turn with it.

Reading resistor colors

Resistors aren’t labeled with numbers; they use colored bands. Read from the side away from the gold band. Not sure? Use the DigiKey color code calculator.

10 kΩ

brown (1) · black (0) · orange (×1000) = 10 000 Ω. Used ×2 for the eyes.

220 Ω

red (2) · red (2) · brown (×10) = 220 Ω. Used ×2 for the LEDs.

03 · Build

Wire it on the breadboard

First build everything flat on the breadboard and test it. Only after it works do you move the eyes onto the servo (step 06). Unplug the USB cable while you wire.

Breadboard basics. The long rails along the edge are connected horizontally (red + for 5V, blue − for GND). In the middle area, each numbered column of 5 holes (a–e) is connected vertically. Two legs in the same column are connected. New to breadboards? Read SparkFun: How to use a breadboard.

Polarity matters for three parts. The capacitor (stripe = −; backwards it can pop), the LEDs (long leg = +) and the servo (brown/black = GND). Photoresistors and resistors work either way round.

Wiring checklist

0 / 8 done
  1. Power railsUSB unplugged. Wire Arduino 5V → red + rail and GND → blue − rail.
  2. Left eye dividerLDR in columns 3 and 5. Jumper col 3 → +. 10 kΩ col 5 → −. Yellow jumper col 5 → A0.
  3. Right eye dividerSame pattern in columns 8 and 10. Green jumper col 10 → A1.
  4. Test the eyesPlug in USB, upload the test sketch, open the Serial Monitor. Cover each LDR with a finger — its number should drop.
  5. Servo + capacitorUnplug USB. Push 3 header pins into columns 26–28, plug the servo in (brown on 26). Wire 26 → −, 27 → +, 28 → pin 9. Add the 100 µF capacitor across the rails.
  6. Indicator LEDs (optional)Pin 5 → 220 Ω → left LED; pin 6 → 220 Ω → right LED. Short legs to −.
  7. Upload Light SeekerUpload the full sketch. The servo jumps to 90° (straight ahead). Shine light on one eye — the LED on that side lights and the servo turns.

04 · Program

The code

Install the free Arduino IDE, plug in the UNO, then pick Tools → Board → Arduino UNO and Tools → Port (the one that appears when you plug in). Paste a sketch, click the → Upload arrow.

Sketch A · Test the eyes first

This only prints the two readings. Open Tools → Serial Monitor and set it to 9600 baud. Cover and uncover each LDR and watch the numbers move.

eye_test.ino
// Sketch A: print both light readings so you can check the wiring

void setup() {
  Serial.begin(9600);          // open the Serial Monitor at 9600 baud
}

void loop() {
  int left  = analogRead(A0);  // 0 = dark ... 1023 = very bright
  int right = analogRead(A1);

  Serial.print("L: ");
  Serial.print(left);
  Serial.print("   R: ");
  Serial.println(right);

  delay(200);                  // 5 readings per second
}
What to expect. Room light: roughly 300–700 on both. Finger over an eye: drops below ~150. Phone flashlight: 850+. If both numbers are nearly the same when uncovered, great. If one is always ~50–100 higher, note the difference; you’ll use it as OFFSET below.

Sketch B · Light Seeker

light_seeker.ino
/*
  Light Seeker: a servo head that turns toward the brightest light.
  Built with the Arduino Starter Kit.
*/
#include <Servo.h>

Servo neck;                  // the servo that turns the head

const int LEFT_EYE  = A0;    // left photoresistor divider
const int RIGHT_EYE = A1;    // right photoresistor divider
const int SERVO_PIN = 9;
const int LEFT_LED  = 5;     // lights while turning left
const int RIGHT_LED = 6;     // lights while turning right

const int DEADBAND = 25;     // ignore differences smaller than this
const int STEP     = 1;      // degrees to move each loop
const int OFFSET   = 0;      // calibration: added to the right eye

int angle = 90;              // start looking straight ahead

void setup() {
  neck.attach(SERVO_PIN);
  neck.write(angle);
  pinMode(LEFT_LED, OUTPUT);
  pinMode(RIGHT_LED, OUTPUT);
  Serial.begin(9600);
  delay(500);                // let the servo reach 90 degrees
}

void loop() {
  int left  = analogRead(LEFT_EYE);
  int right = analogRead(RIGHT_EYE) + OFFSET;
  int diff  = left - right;

  if (diff > DEADBAND) {
    angle = angle + STEP;           // left is brighter: turn left
    digitalWrite(LEFT_LED, HIGH);
    digitalWrite(RIGHT_LED, LOW);
  } else if (diff < -DEADBAND) {
    angle = angle - STEP;           // right is brighter: turn right
    digitalWrite(LEFT_LED, LOW);
    digitalWrite(RIGHT_LED, HIGH);
  } else {
    digitalWrite(LEFT_LED, LOW);    // about equal: hold still
    digitalWrite(RIGHT_LED, LOW);
  }

  angle = constrain(angle, 0, 180); // servo can only do 0..180
  neck.write(angle);

  Serial.print("L: ");       Serial.print(left);
  Serial.print("  R: ");     Serial.print(right);
  Serial.print("  angle: "); Serial.println(angle);

  delay(15);                 // small pause so the servo can keep up
}
LineWhat it means
#include <Servo.h>Loads the Servo library (already installed with the IDE).
const int DEADBAND = 25;How different the eyes must be before the head moves. Bigger = calmer but less precise.
analogRead(A0)Measures 0–5 V and returns 0–1023. Reference.
diff = left - rightPositive → left eye sees more light. Negative → right eye does.
constrain(angle, 0, 180)Keeps the angle inside what the servo can do. Reference.
neck.write(angle)Tells the servo which angle to go to. Reference.
delay(15)Waits 15 ms. Raise to 30 for slower, smoother tracking.
05 · Mount

Build the cardboard head

For real light-following, the eyes must turn with the servo. Otherwise it can never tell when it’s facing the light. A strip of cardboard on the servo horn does the job.

  1. Cut the baseA cardboard strip about 8 × 3 cm. Poke a hole in the middle for the horn screw, or just hot-glue/tape it to the long servo horn.
  2. Add the wallGlue a 3 × 4 cm cardboard wall standing up in the middle, pointing forward.
  3. Place the eyesPush each LDR’s legs through the base, one on each side of the wall, faces up and slightly outward.
  4. Connect with long jumpersPull each LDR out of the breadboard and replace it with two jumper wires going to the same holes. Twist each LDR leg tightly around a jumper tip and wrap with tape (or use female–male jumpers if you have them). Leave slack so wires don’t pull when the head turns.
  5. Center firstPower up, let the servo go to 90°, then press the horn on so the head faces straight forward.
  6. PlayDim the room, shine a phone flashlight from ~50 cm away and move it slowly left and right.
06 · Debug

Troubleshooting

Almost every problem shows up in the Serial Monitor. Keep it open while testing.

The head turns away from the light

Your servo turns the other way, or the eyes are swapped. Easiest fix: swap the yellow and green wires at A0 and A1. Or in the code swap angle + STEP and angle - STEP.

A reading is stuck at 0 or 1023

Stuck at 1023: the 10 kΩ resistor isn’t reaching the − rail (or the jumper went to + by mistake). Stuck at 0: the LDR isn’t reaching the + rail, or the A0/A1 wire is in the wrong column. Check that the LDR leg, the resistor and the A0 wire share one column.

Tip: many breadboards have a break in the middle of each rail. If your rail lines have a gap, bridge it with a short jumper.

The servo shakes or twitches when it should hold still

Increase DEADBAND to 40–60. Also check the 100 µF capacitor is in (stripe to −). Room lights that flicker (some LEDs) add noise; try daylight or a flashlight.

The Arduino resets or disconnects when the servo moves

The servo is pulling more current than USB can give. Make sure the capacitor is installed, use a short USB cable plugged straight into the computer (not a hub), and don’t press on the horn while it moves.

It always drifts to one side

The two LDRs aren’t identical. With both eyes in the same light, read L and R in the Serial Monitor. If L is always ~60 higher, set OFFSET = 60. If R is higher, use a negative number.

Upload fails (“port not found” / “not in sync”)

Choose the right board and port in the Tools menu, try another USB cable (some are charge-only), and close the Serial Monitor in other windows. See the official upload troubleshooting guide.

07 · Level up

Ideas once it works

Proportional speed

Move faster when the difference is big: angle += diff / 50; instead of a fixed step. Smoother and quicker.

Brightness buzzer

Add the kit’s piezo and play a tone whose pitch rises with left + right. Now it sings when it finds the light.

Solar tracker

Stick a tiny solar cell on the head. This exact idea is how real solar panels follow the sun.
